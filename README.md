# Карельский гид — голосовой путеводитель в Telegram

Бот [@FRS_HSE_bot](https://t.me/FRS_HSE_bot) отвечает на вопросы о Карелии текстом и голосом.
Есть мини-приложение с кнопкой микрофона и картой Карелии.

## Запуск

Дважды щёлкните `Запустить бота.bat` или выполните:

```
.venv\Scripts\python run.py
```

В окне появится адрес мини-приложения. Бот работает, пока открыто окно и включён компьютер.
Чтобы остановить бота, нажмите `Ctrl+C`.

Проверить всё без Telegram можно так: `.venv\Scripts\python tools\selftest.py`.

## Как пользоваться

* В чате с ботом отправьте **голосовое сообщение** с вопросом: «Как добраться до Кижей?».
  Бот распознает речь, ответит текстом с источниками и голосовым сообщением.
* Можно уточнять: «а сколько стоит?», «как туда добраться?» — бот помнит, о каком месте шла речь.
* `/places` выводит список мест. Под каждым ответом есть кнопка «на карте».
* Кнопка **«Путеводитель»** слева от поля ввода открывает мини-приложение: микрофон, чат и карта
  с границей Карелии, точками мест и маршрутом в Яндекс Картах.

## Как это устроено

| Часть | Что делает | Где |
|---|---|---|
| Распознавание речи | faster-whisper (модель `small`) прямо на этом компьютере, около 2 с на вопрос | `app/stt.py` |
| Ответы | Без ключа — поиск по собранной базе знаний. С ключом Claude — Claude отвечает по той же базе | `app/knowledge.py`, `app/llm.py` |
| Озвучка | Голос Microsoft Svetlana (edge-tts), голосовые в формате OGG/Opus | `app/tts.py` |
| Бот | aiogram 3, голосовые и текстовые вопросы, кнопки | `app/bot.py` |
| Мини-приложение | FastAPI + страница с картой Leaflet/OpenStreetMap | `app/server.py`, `webapp/` |
| Публичный адрес | Cloudflare Quick Tunnel (`bin/cloudflared.exe`), новый адрес при каждом запуске | `app/tunnel.py` |

База знаний лежит в `data/`. В `places.json` 11 мест: Кижи, Рускеала, Валаам, Кивач,
Марциальные воды, Петрозаводск, онежские и беломорские петроглифы, Ладожские шхеры, Воттоваара,
Паанаярви. В `faq.json` — общие вопросы о Карелии, в `sources.json` — источники.

В `data/audio/` лежат живые озвучки описаний: файл называется по id места (`kizhi.m4a`,
`ruskeala.m4a`…; подходят .m4a, .mp3, .ogg, .wav). Когда гид рассказывает о месте целиком
(«Расскажи про Кижи», кнопка «Послушать», список `/places`), играет запись, а не синтезатор.
Ответы на конкретные вопросы (цены, как добраться) по-прежнему озвучиваются синтезатором.
Записи пока нет только для Ладожских шхер — положите `ladoga_skerries.m4a`, перезапуск не нужен.
Факты взяты с официальных сайтов 07.10.2026.

## Список источников

`Список использованных источников.docx` — 38 источников. Записи оформлены по ГОСТ Р 7.0.100–2018,
страница — по ГОСТ 7.32–2017: Times New Roman 14, интервал 1,5, поля 30/15/20/20 мм.
Если поменяли `data/sources.json`, пересоберите файл:

```
.venv\Scripts\python tools\make_sources_docx.py
```

## Настройки (`.env`)

* `ANTHROPIC_API_KEY` — ключ Claude. Вставьте его и перезапустите бота: ответы станут гибче.
  Модель задаёт `CLAUDE_MODEL` (по умолчанию `claude-opus-5-5`, низкая «глубина размышлений»
  `CLAUDE_EFFORT=low` ради скорости). Если API недоступен напрямую, укажите `ANTHROPIC_PROXY`.
* `ALLOWED_USER_IDS` — id друзей в Telegram через запятую, чтобы ботом не пользовались чужие.
  Свой id можно узнать у бота @userinfobot.
* `WHISPER_MODEL` — модель распознавания. `small` быстрее и на этом ноутбуке точнее `large-v3-turbo`.
* `TTS_VOICE` — голос: `ru-RU-SvetlanaNeural` или `ru-RU-DmitryNeural`.
* `PUBLIC_URL` — постоянный HTTPS-адрес, если он появится. Тогда туннель не нужен.

## Ограничения

* Компьютер должен быть включён, а бот — запущен.
* Адрес мини-приложения меняется при каждом перезапуске. Бот сам обновляет кнопку «Путеводитель»,
  но кнопки в старых сообщениях перестают работать.
* Если у друзей мини-приложение не открывается (провайдер блокирует Cloudflare), голосовые
  вопросы в чате всё равно работают: они идут через серверы Telegram.
* Цены и расписания собраны в октябре 2026 года. Перед поездкой их стоит уточнить на сайтах.
